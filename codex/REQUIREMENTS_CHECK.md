## Data Exploration guiding questions, all 9 groups

1. **Inputs:** schema names and types; IDs used exclusively for grouping.
2. **Splitting:** fixed respondent partition, validation for model selection,
   local test for one final estimate; EDA uses training only.
3. **Distributions:** summary of every input, detailed training histograms,
   near-constant check, numeric Spearman correlations. No original constant input.
4. **Imbalance:** 202 rows per class in training; no balancing needed presently.
5. **Missingness:** normalize markers first, report all rates, compare rates by
   class, acknowledge unknown mechanisms, median/empty text plus indicators;
   never estimate imputation from validation/test.
6. **Outliers:** IQR flagging used diagnostically, genuine high prices retained
   through train-fitted 99th-percentile cap/log; out-of-range ease becomes missing.
7. **Engineering:** multi-hot; ordinal tradeoff; conservative monetary parsing;
   exact TF-IDF settings/formula; OOV behavior; high-dimensional regularization.
8. **Scaling:** standardization versus min-max, which model mechanisms need it,
   no scaling of binary/TF-IDF blocks, fitting statistics inside each fold.
9. **Predictiveness:** numeric means/SDs, multi-option class rates, token support,
   class differences compared with within-class spread; exploratory findings
   motivate model choices without validation feature selection.

## Methodology guiding questions, all 7 groups

1. **Families:** simple regularized models before a large network; linear text
   evidence, nonlinear rules and local similarity each have a role.
2. **Training:** all implementation settings and overfitting responses documented;
   no MLP is proposed, so no fabricated MLP architecture is specified.
3. **Validation:** grouped 5-fold split and fold-local preprocessing, with tests
   against respondent overlap and preprocessing refit at transform time.
4. **Tuning:** grids, boundary review, and why a final train+validation refit trades
   a validation set for more fitting data.
5. **Fair comparison:** tune all three, log mean/SD, treat small gaps cautiously;
   equal candidate counts are not claimed to make searches exhaustive.
6. **Metrics:** accuracy and macro-F1, per-class precision/recall, constant baseline;
   macro versus support-weighted averaging explained.
7. **Additional techniques:** no PCA or clustering is proposed; these are optional.
   Structured-only ablations may be tested within training CV before validation.

## Scope and reproducibility

- All report numbers are supported by `analysis/`, which is regenerated by
  `explore.py`; all numeric assertions in the PDF were checked against those files.
- Full tuning, final held-out testing and restricted prediction export are later
  work, not prerequisites for a completed proposal with a planned methodology.
- All development code may use sklearn; the import restrictions belong to the
  separate final `pred.py` and are explicitly accounted for in the plan.
- No signature, claim of individual contribution, or group review is fabricated.
- Main text remains 12 point, one column, one-inch margins; Data Exploration is
  2 pages and Planned Methodology is 3 pages. References are separate.
